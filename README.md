# Noise Control 音訊降噪

Noise Control 是人聲降噪音訊工作台，支援錄音檔與麥克風即時收音，可播放、比較並下載原始與降噪版本。

## 兩種音訊來源

- 錄音檔：上傳 WAV、MP3、M4A，伺服器處理後提供原始及降噪 WAV，可播放及下載。
- 麥克風：開始收音後持續傳送約 250 毫秒的 PCM 音訊，伺服器逐段降噪並即時回傳；停止後保存完整的原始及降噪 WAV。
- 耳機監聽可切換原始或降噪版本。預設關閉，避免揚聲器聲音回到麥克風。
- 降噪強度可在收音中調整；變更只套用到後續收到的音訊。
- 原始／降噪音軌各有播放、進度拖曳、靜音與倍速控制，播放其中一個版本時會暫停另一個。
- 可選輕度、均衡、強力預設，或使用滑桿自訂強度。
- 範例選單提供風扇與白噪音、60 Hz 低頻嗡聲、模擬風聲、模擬鍵盤敲擊、強噪音及乾淨人聲 6 種合成音訊；選擇後按旁邊的載入圖示，可先播放原音，再按「開始降噪」比較。雙人聲分離模式另有專用範例。
- 右上角的歷史圖示可開啟「音訊紀錄」，每次開啟都會自動取得最新紀錄；重新載入網頁後仍可查看同一 Session 的暫存結果、下載、載入或刪除，也可確認後全部刪除。配額不足時會自動開啟紀錄視窗。
- 波形與音訊載入各有逾時處理；波形失敗不會鎖住操作，音軌載入失敗會顯示錯誤及重試圖示，不會誤顯示結果已完成。

麥克風是在收音期間持續處理，不必等錄音結束。這是分段即時處理，仍有約 250 毫秒的收集時間、網路往返、處理及播放緩衝的延遲，不適合零延遲通話用途。

## AI 人聲降噪

- 使用 RNNoise 神經網路人聲降噪，預設均衡 85%；輕度／均衡／強力分別是 50%／85%／100%。0% 保留原音，較低強度會混回部分原音。
- 可選擇關閉／50 Hz／60 Hz 低頻嗡聲抑制，上傳與即時收音共用；收音開始後設定固定，避免中途重建濾波器。預設關閉以免影響沒有嗡聲的人聲。
- 可另外配置高資源的雙人聲分離服務，供最長 15 秒的錄音檔使用，回傳兩路 8 kHz 人聲供試聽選擇。不是即時麥克風或身分識別；未配置時不顯示選項。
- 主要保留人聲，壓低風扇、冷氣、底噪等背景聲；音樂、樂器與自然環境音也可能被當作噪音消除。
- 錄音檔與麥克風使用相同模型，保留取樣率、聲道數與完整長度；麥克風模型狀態只在該次錄音內保留，停止時會補回緩衝尾端，不會截掉最後一段話。
- 推論由伺服器執行，不呼叫第三方 AI API，也不會把音訊另傳到模型供應商。
- 這不是耳機的主動降噪（ANC）：它改善錄到／傳出去的聲音，無法抵銷你耳邊真實的環境聲。
- 無法保證完全消除噪音，也不會辨識「哪一個人」是要保留的說話者；其他人說話、尖銳瞬間聲、嚴重風切、回音或破音仍可能殘留。降噪越強也可能產生音質變化，必要時調低強度。

模型來源與聲明見 [backend/models/README.md](backend/models/README.md)。實驗性的雙人聲分離使用 [SpeechBrain SepFormer Libri2Mix](https://huggingface.co/speechbrain/sepformer-libri2mix)，人聲編號不代表固定身分。

## 使用限制

- 音訊會傳到伺服器進行解碼、處理與暫存。
- 上傳大小最多 25 MB；檔案及麥克風每次最長 120 秒。
- 支援單聲道、立體聲及 8–48 kHz。結果統一輸出 16-bit PCM WAV。
- 暫存音訊一小時後自動清理；服務重啟也可能使音訊提前失效，重要結果請自行下載。
- 每個 Session 暫存上限為 64 MiB 或 20 筆結果；這不是永久音訊庫。
- 處理容量與請求頻率有限，忙碌或配額不足時會提示稍後重試或刪除暫存音訊。
- 麥克風需要瀏覽器授權與安全連線，監聽建議使用耳機。

## 音訊隱私

- 不需要註冊，使用瀏覽器的匿名 Session 區分音訊擁有者。
- 原始與降噪音訊、紀錄列表與刪除操作都限定目前 Session，不提供公開分享連結。
- 到期或刪除後會撤銷新請求的存取；已下載的副本無法遠端收回。
- 清除 Cookie、換瀏覽器或 Session 過期後，原連結不再可用。這不是跨裝置帳號音訊庫。
- 伺服器需要解碼與處理音訊，因此這不是端對端加密；主機管理者仍可存取伺服器儲存。
