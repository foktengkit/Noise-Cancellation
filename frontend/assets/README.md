# Synthetic examples

The six denoising examples use Microsoft Hanhan Desktop synthetic speech with
deterministic simulated noise. They contain no user recording. Their provenance,
noise settings and regeneration commands are documented in `SAMPLE.md`.

`sample-speakers.wav` is an eight-second, 8 kHz mono mixture of Microsoft Hanhan
Desktop and Microsoft Zira Desktop synthetic English phrases. The sources are
generated by `scripts/synthesize_separation_speech.ps1`; the mixture is generated
by `scripts/evaluate_separation.py --publish-sample`. It contains no user recording.
The source references and model outputs remain in ignored test artifacts.
